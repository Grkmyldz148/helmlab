# Plain, data-based language

## Context and Problem Statement

Earlier texts used superlatives and win counts that later had to be withdrawn.

## Considered Options

* Promotional language
* Plain language with labelled data

## Decision Outcome

Chosen option: "Plain language with labelled data": no superlatives; every figure names its dataset, its size (n), and whether that data was used to fit, tune or design the model; losses appear in the same table. READMEs, docstrings and skills carry no performance figures and link to the evidence page instead.

### Consequences

* Good, because every claim can be checked.
* Bad, because the texts promote less.
