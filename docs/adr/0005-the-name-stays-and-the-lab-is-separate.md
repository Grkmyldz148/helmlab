# The name Helmlab stays; research is a separate project

## Context and Problem Statement

"Helmlab" was the name of one color space. The project now publishes frozen definitions, tools and data. Research needs private data, drafts and failed experiments.

## Considered Options

* Rename the project
* Keep the name for the project and keep research in a separate private repository

## Decision Outcome

Chosen option: "Keep the name for the project and keep research in a separate private repository" (`lab`). Each definition is named Helmlab plus the year in which it is frozen, for example Helmlab 2026; at most one definition is frozen per calendar year.

### Consequences

* Good, because existing packages, links and the paper keep working.
* Bad, because "Helmlab" names both the project and its definitions, so texts have to say which one they mean.
