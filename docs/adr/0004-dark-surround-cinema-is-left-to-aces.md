# Dark-surround cinema viewing is left to ACES 2.0

## Context and Problem Statement

Cinema is viewed in a dark surround, which needs appearance modelling of its own.

## Considered Options

* Model the dark surround in Helmlab
* Leave it to ACES 2.0

## Decision Outcome

Chosen option: "Leave it to ACES 2.0", because it already covers that viewing condition.

### Consequences

* Good, because Helmlab does not duplicate an established system.
* Bad, because Helmlab does not model a dark surround.
