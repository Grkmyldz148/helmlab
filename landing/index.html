Quick Start

Works where you work

Python and JavaScript with identical APIs. TypeScript types included. Zero dependencies in JS.

from helmlab import Helmlab

hl = Helmlab()

# sRGB → Helmlab Lab
lab = hl.from_srgb([0.2, 0.5, 0.8])

# Perceptual distance
dist = hl.delta_e("#ff0000", "#00ff00")

# 32-step gradient
grad = hl.gradient("#0000ff", "#ffffff", 32)

# Tailwind-style semantic scale
scale = hl.semantic_scale("#3b82f6")

FAQ

Frequently Asked Questions

What is Helmlab?

Helmlab is a family of two purpose-built color spaces: GenSpace for creating beautiful gradients and palettes, and MetricSpace for measuring perceptual color differences. Both are exactly invertible, open-source, and available for Python and JavaScript.

How is Helmlab different from OKLab?

OKLab is a hand-designed color space built into CSS. Helmlab's GenSpace wins 50 out of 61 benchmarks against OKLab, including 360/360 gamut cusps (OKLab: 299), 93x better Munsell Value accuracy, and 31-million-times better gray achromatic precision. Helmlab's MetricSpace also provides a trained perceptual distance metric (STRESS 23.30 on COMBVD), which OKLab cannot offer.

Is Helmlab free?

Yes. Helmlab is fully open-source under the MIT license. Use it in personal projects, commercial products — no attribution required (though appreciated).

Can I use it in production?

Yes. The JavaScript package is ~10KB gzipped with zero dependencies and ships with TypeScript types. The Python package uses NumPy for batch operations. Both have full test suites (607 tests combined) and are published on npm and PyPI.

Does it work with Tailwind / Figma / CSS?

Tailwind: Use semanticScale() to generate 50–950 scales, then export directly to Tailwind config format.

CSS: Export palette as CSS Custom Properties with one function call. Also available as a <script> tag from CDN.

Figma: No plugin yet, but you can generate palettes in code and paste hex values.

Is there a peer-reviewed paper?

The full methodology, evaluation, and ablation study are published as an arXiv preprint: arXiv:2602.23010. The paper describes the pipeline, optimization procedure, cross-validation results, and comparison with 8 baseline methods.
