Helmlab

Helmlab defines color spaces for generating colors (gradients, palettes, gamut mapping) and for measuring color differences, and publishes their reference code.

Current definition: Helmlab 2026

Helmlab 2026 is defined by the outputs of helmlab 1.0.0 on npm and PyPI. helmlab 1.0.1 has identical outputs; only its JavaScript speed and documentation changed.

IdentifierWhat it names
helmgenGenSpace in Lab coordinates, for generating colors
helmgenlchGenSpace in LCh coordinates (lightness, chroma, hue)
helmlab-metricMetricSpace, for measuring color differences
ΔE helmlabColor difference computed from helmlab-metric coordinates

A specification and test vectors for Helmlab 2026 are planned.

Install

npm i helmlab
pip install helmlab

API reference: API.md. Changes by version: CHANGELOG.md.

Other implementations

These libraries are maintained outside Helmlab: Color.js, ColorAide and color-space.

Known issues

  • Color.js 0.7.1 and ColorAide 8.13.1 implement helmlab-metric without the neutral-correction step, so their a and b values differ from those of the helmlab package. color-space 3.5.0 includes the step.
  • The paper's description of the neutral-correction step differs from the released code; see helmlab#4.
